Overview

MDConverter provides a free REST API. No API key required. Send any supported file and get Markdown back as JSON.

Base URL: https://mdconverter-web-production.up.railway.app

Convert a File

POST/api/convert

Send a file as multipart/form-data with the key file. Returns JSON with the Markdown content.

PYTHON EXAMPLE

import requests

with open("myfile.pdf", "rb") as f:
    response = requests.post(
        "https://mdconverter-web-production.up.railway.app/api/convert",
        files={"file": f}
    )

data = response.json()
print(data["markdown"])

CURL EXAMPLE

curl -X POST \
  https://mdconverter-web-production.up.railway.app/api/convert \
  -F "file=@yourfile.pdf"

Response Format

{
  "success": true,
  "filename": "yourfile.pdf",
  "markdown": "# Your converted content here..."
}

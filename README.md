MDConverter Web 🗂️➡️📝
A free, simple web app to convert documents and files into Markdown (.md) format — powered by Microsoft's MarkItDown library.
Just upload your file, give it a name, and download the converted Markdown instantly. No installation required.

🌐 Live App
👉 mdconverter-web-production.up.railway.app

✅ Supported File Types
CategoryFormatsMicrosoft Office.docx, .xlsx, .xls, .pptxPDF.pdfImages.jpg, .jpeg, .pngAudio.mp3, .wavWeb.htmlData.csv, .json, .xmlArchives.zip

🚀 How to Use

Go to the live app
Click Browse and select your file
Enter a name for the output file
Click Convert & Download
Your .md file downloads automatically


🛠️ Run Locally
If you want to run this on your own machine:
1. Clone the repository
bashgit clone https://github.com/yourusername/mdconverter-web.git
cd mdconverter-web
2. Install dependencies
bashpip install -r requirements.txt
3. Run the app
bashpython app.py
4. Open in your browser
http://localhost:5000
